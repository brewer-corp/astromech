Most journal mod symbols do not match the catalogue ids, so mod_ids (owned.rs:68-84) silently drops them and the picker keeps offering mods already fitted. Real SuitMods/WeaponMods strings include suit_backpackcapacity (catalogue extrabackpackcapacity), suit_improvedradar (enhancedtracking), suit_increasedammoreserves (extraammocapacity), suit_increasedbatterycapacity (improvedbatterycapacity), suit_increasedmeleedamage (addedmeleedamage), suit_adsmovementspeed (combatmovementspeed), suit_increasedo2capacity (increasedairreserves), weapon_accuracy (improvedhipfireaccuracy), weapon_backpackreloading (stowedreloading), weapon_clipsize (magazinesize), weapon_handling (fasterhandling), weapon_range (greaterrange), weapon_suppression_unpressurised (audiomasking). Only nightvision/improvedjumpassist/increasedsprintduration/reducedtoolbatteryconsumption/headshotdamage/reloadspeed/stability-style names line up. The fixture invents suit_increasedairreserves, so the test passes against a string the game never writes. Fix: an explicit journal-symbol -> catalogue-id map (e.g. in odyssey.json), confirm the remaining ones (damage resistance, shield regen, quieter footsteps, scope, noise suppressor), fixture with real strings. Evidence: https://github.com/jixxed/ed-journal-schemas/blob/main/schemas/SuitLoadout/SuitLoadout.json, https://github.com/jixxed/ed-journal-schemas/blob/main/schemas/SwitchSuitLoadout/SwitchSuitLoadout.json, https://github.com/jixxed/ed-journal-schemas/blob/main/schemas/CreateSuitLoadout/CreateSuitLoadout.json (items examples).
