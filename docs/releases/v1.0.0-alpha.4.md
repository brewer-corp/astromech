# astromech v1.0.0-alpha.4

The fourth 1.0 alpha. It follows v1.0.0-alpha.3. The Galaxy area is reworked: the route you are following is on every page, every "where is" search lives in Places, and one box in the header finds pages and plots routes. The window also takes on the game's own orange look. This is an alpha. It reaches you through the in-app updater, with no separate pre-release channel.

**Installing.** The build is unsigned, so Windows SmartScreen says "Windows protected your PC" (More info, then Run anyway). It installs per user, with no admin rights. First install: run the setup.exe. Later versions: tray, **Check for updates**, then **Restart to update**. The release's `SHA256SUMS.txt` lists the checksums. The [guide](https://github.com/brewer-corp/astromech/blob/main/docs/guide/index.md) covers every page.

## What's new since v1.0.0-alpha.3

### Routes and finding places

- **The route on every page.** A strip under the header shows the next waypoint with a copy button, where you are in the route, what is there (neutron boost, fuel, an engineer), and how many jumps are left to the destination. It says **Off route** when you have strayed, and **Refuel before the next jump** at a fuel stop. The Galaxy page's side rail is gone. See [The route strip](https://github.com/brewer-corp/astromech/blob/main/docs/guide/routes.md#the-route-strip).
- **Find or plot.** One box in the header, on every page (Ctrl+K puts the cursor in it), replaces the route rail's Plot panel and the Ctrl+K palette. Type a system to plot a route to it, a finder or what you want ("interstellar factors", "sell painite", "painite hotspots"), a page, a material, a module or a ship. The plot panel no longer closes by itself every few seconds, and there is no **From** box: a route always starts from where you are. See [Find or plot](https://github.com/brewer-corp/astromech/blob/main/docs/guide/using-the-app.md#find-or-plot).
- **Places.** The Galaxy tab's pages are now **Places** and **Route**. Places has a tile for each finder: Sell, Buy and Sell my cargo (moved from Trade), Services, Outfitting, Shipyard, Material traders, Raw sites and Faction states (moved from Materials), and Mining hotspots. Each finder is its own page, and its tile shows the last answer you got. Trade, Materials and Exploration link to the finder instead of listing places themselves. See [Places](https://github.com/brewer-corp/astromech/blob/main/docs/guide/places.md).
- **Mining hotspots.** A new finder lists the rings with the most hotspots of a mineral near you, the next stop or a system you type, with ring type and reserve. By voice: "nearest painite hotspot". See [Mining hotspots](https://github.com/brewer-corp/astromech/blob/main/docs/guide/places.md#mining-hotspots).
- **Add stop and Set destination.** Every search result has two buttons in place of Go, which used to replace your route without saying so. **Add stop** makes the result the next stop and keeps the rest of the route. **Set destination** makes it the whole route, and pauses the route it replaced so **Resume** brings it back. See [From a search result](https://github.com/brewer-corp/astromech/blob/main/docs/guide/routes.md#from-a-search-result).
- **Routes plotted in the galaxy map are followed.** A leg of the route you are following changes nothing, so a neutron route survives plotting each leg. Any other plot becomes the route, followed silently with the clipboard left alone; a route of your own it replaces is paused. Clearing the route in the galaxy map stops following it. See [Routes plotted in the galaxy map](https://github.com/brewer-corp/astromech/blob/main/docs/guide/routes.md#routes-plotted-in-the-galaxy-map).
- **Spansh's neutron routes count every jump.** A neutron route plotted by Spansh used to show its number of legs as its jumps (Sol to Colonia said 128). It now says 166.
- **Search results read left to right.** The value a search ranks by (price, total, jumps) comes first, then the place, then distance, jumps, pad, arrival and report age in aligned columns.

### Voice

- **Search from a named system.** "Where can I sell gold near Sol", "interstellar factors around Shinrarta Dezhra", "in" and "from" too. "Near me", "in bulk" and "in large quantities" still search from where you are.
- **Everyday questions are not exploration questions.** "What is in this system", "how much is my ship worth" and the like get "Say again" instead of an exploration answer they didn't ask for.

### The app window

- **The game's orange.** The window moves from grey to Elite's orange ramp, with caps headings and one typeface (Saira, with figures that line up). A box you can type in or change looks like one; read-only facts sit on the panel.
- **Two rows of tabs at most.** Third-level tabs (Materials kinds, On foot views, a ship's Info and Engineering) became choices on the page.
- **Setup and Settings.** Setup says "Checking…" or "Could not read" instead of "Not set" before it has read your status. A repeated "Saved" or error is read out again by screen readers.
- **The right config file.** The window no longer follows a config file left behind by a core that has crashed or quit.

### Journal and data sharing

- **The journal the game is writing.** At startup, and after a clock correction, astromech follows the journal the game is writing now, not an older one a backup or sync tool touched last. Lines the game writes while astromech is catching up at startup count as live, so their callouts are spoken.
- **EDSM after an outage.** Events EDSM refused are sent in batches once it is back, and astromech waits when EDSM says it is sending too fast.
- **Neutron star file.** When the download can't reach the server, the log says why.
- **Links.** The app refuses to open a link whose path climbs out of the sites it is allowed to open.

## What has not been checked in the game

Everything below needs Elite running. These are alpha.1's four sessions, with what is new in this alpha added. Play them in order, on Windows, with the app installed from this release. Each step says what to do and what to look for. Write down a result for each issue ID as you go.

### Session 1: trading, outfitting and engineering

Dock at a station with a market and outfitting, with the app window open. Use a ship you know well.

- **The galaxy rework next to the game** (astromech-cxgq). Do: follow a route through this session. Look at the route strip and header at Windows display scaling 100, 125 and 150 %, and on a second monitor with the window at its narrowest (1100 px). From a finder, press **Add stop**, then **Set destination**, and paste each into the galaxy map. Jump, and plot a route from **Find or plot**. Look for: nothing wraps or clips; the right system is on the clipboard and pastes; the strip moves on after each jump; the route starts from where you are. Keep screenshots out of the repository and note each problem.
- **Sell at a suggested station** (astromech-1per). Do: from the Commodities page, ask "where do I sell" a commodity you carry, fly to the first answer and sell one load. Look for: the price matches the quote, allowing for the age of the data.
- **Buy from an outfitting lookup** (astromech-4su3). Do: ask for a module, then a ship, then a service, by voice and from its Places finder, and go to the top answer for each. Look for: the station really sells each one.
- **Engineering lookups** (astromech-fipx). Do: ask where to find an engineer or a material for a blueprint you need. Look for: the top answers hold from where you are.
- **Ships page build questions** (astromech-fgv5). Do: for one of your ships, answer the distributor, FSD and shield booster questions from the Ships page alone. Then compare with Coriolis and with the fitted ship in the game. Look for: all three agree within displayed rounding. In the build planner, set a target at a module's own grade, fully rolled, and check its values don't change. Also look at a real Loadout with an old (pre-3.0) module and a pre-engineered SCO drive, and note which Modifier labels the game writes.
- **Materials page timing** (astromech-rggm). Do: with the window on Materials, make five changes (collect, discard, trader swap, engineer roll, synthesis). Look for: each shows within 2 s. Then open Engineering, Builds and check that it also follows the game within a second or two.
- **Coriolis and EDSY links** (astromech-ww05). Do: on Builds and on a ship's Info page, with a large engineered ship, click one Coriolis and one EDSY link. Look for: the right build opens in your browser, with the long address and the EDSY `#` part intact.
- **On foot events** (astromech-d0zh). Do: buy, upgrade and sell a suit and a weapon, and save a loadout with mods. Look for: the On foot page shows the right grades and mods, with no `odyssey: unknown` line on stderr (the release app has no console, so use a debug build or `cargo tauri dev`).
- **Odyssey game data** (astromech-h9ch). Do: compare the weapon upgrade prices the wiki leaves blank, the sale prices of a few data and goods items and the engineer and mod pairs, including Manticore Intimidator grade 2 and Tormentor grade 2. Look for: each value matches the game, or note the correction.
- **Bartender barter rules** (astromech-t71i). Do: at a bartender, try to swap goods and data, swap assets for equal barter value, ask for something large, and overshoot a trade. Look for: whether goods and data can be bartered, whether the rate is equal both ways, and what an overshoot does.
- **Backpack and ShipLocker files** (astromech-t8hg). Do: watch the modified times of `Backpack.json` and `ShipLocker.json` while you do each on-foot action once (pick up, drop, transfer, use, death). Look for: which action rewrites which file.
- **Offer the charge-time fix to Coriolis** (astromech-mf7w). This one needs no game. Do: open a pull request or an issue on EDCD/coriolis about sustained damage above burst for charged weapons. Look for: it is open and linked on the issue.

### Session 2: mining and callouts

Mine in a ring with a prospector limpet launcher and refinery, with callouts at their defaults.

- **Mining with the reaction callouts** (astromech-6920). Do: mine for 20 minutes or more, firing prospectors. Before that, launch a repair or fuel limpet. Look for: the other limpet does not start a run, the prospector and scan callouts fire correctly, repeat prospects do not repeat, cooldowns hold, and the Mining page shows tons refined and tons per hour that match your cargo.
- **Arrival, docking and route callouts** (astromech-505u). Do: play a session of jumps, a supercruise arrival, a docking and a followed route. Start astromech once while Elite is already running. Look for: each callout fires when it should, nothing the HUD already shows is spoken, speech is quiet in a fight or while docking, and nothing from before the start is spoken.
- **Callout notifications on Windows** (astromech-g80r). Do: trigger a callout that also shows a notification, once normally, once with PowerShell blocked, and once with Elite fullscreen and Do Not Disturb on. Look for: the notification appears; the log says "notification failed (PowerShell …)" when it cannot; and whether Do Not Disturb shows, holds or loses it.

## Known limits

- **Neutron routes on this PC need the file.** The neutron star file is a one-time download of about 71 MB (184 MB on disk), and uses about 80 MB of memory while the window is open. It is rebuilt by hand now and then, not with each update. Until it is downloaded, Spansh plots neutron routes.
- **Routes plotted on this PC.** They don't plan fuel, and they count the normal jumps between neutron stars from the distance. In sparse space, between the arms and at the galaxy's edge, a leg may take more jumps than the page says, or need a detour. On a long route the search stops at a good route instead of trying every one, so it is near the fewest jumps, and the page says so. There is no Efficiency setting for them. See [Routes](https://github.com/brewer-corp/astromech/blob/main/docs/guide/routes.md#plot-a-route).
- **Plotting.** No FSD injections, via systems or fuel reserve. You still plot each leg in the galaxy map yourself.
- **Voice.** English only, from a fixed list of commands. Flight commands (supercruise, hyperspace jump, docking requests, route plotting) are recognised but do nothing yet. Speech recognition can still mishear game words: say "Did you mean" answers clearly and use the Voice tester to see what it heard. The left and right panel fix follows Frontier's manual and has not been checked in the game. The new "nearest painite hotspot" phrases have not yet been through the speech-recognition test the other phrases passed, so they may be misheard more often.
- **Outfitting for new modules.** A station that lists a module astromech doesn't know yet sends no outfitting for that visit.
- **EDSM is best effort.** astromech sends as much as it can. An event EDSM keeps refusing is given up after several tries, so it may be missing from your flight log.
- **Daylight saving.** The next clock change is in March. astromech relies on Elite naming its journal files in local time, which was confirmed on one machine only. In the repeated hour, a journal can be judged live or old wrongly, so a callout may be missed or an old one spoken.
- **Pages.** The Builds page cannot find one station that sells every module a build still needs. When a status read fails, the header says "Not running" even if the core is running. Info shows approximate pitch, roll and yaw from the ship catalogue, not live telemetry.
- **Unsigned.** The installer is not signed, so SmartScreen warns on each setup.exe. In-app updates are signed and checked.
