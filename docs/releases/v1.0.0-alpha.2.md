# astromech v1.0.0-alpha.2

The second 1.0 alpha. It follows v1.0.0-alpha.1 and ships the window refresh that landed after that build: Trade restyled to the Galaxy lookups, then rank chrome across Engineering, Galaxy, ships, stored modules, unlocks, and the rest of the shell. Behaviour is the same as alpha.1. The orange you see is still Elite's stock `#fa6e00`. This is an alpha. It reaches you through the in-app updater, with no separate pre-release channel.

**Installing.** The build is unsigned, so Windows SmartScreen says "Windows protected your PC" (More info, then Run anyway). It installs per user, with no admin rights. First install: run the setup.exe. Later versions: tray, **Check for updates**, then **Restart to update**. The release's `SHA256SUMS.txt` lists the checksums. The [guide](https://github.com/spadaval/astromech/blob/main/docs/guide/index.md) covers every page.

## What's new since v1.0.0-alpha.1

### Window chrome

- **One orange row.** The main navigation owns the stock Elite orange. Sub-tabs, chips, and in-page toggles sit quieter, so the page you are on is the loud thing. Idle "not running" still reads as loudly as Finish setup.
- **Galaxy Find.** Services, Outfitting, and Shipyard share one typed Find box. Type a service, module, or ship and go; the Galaxy rail keeps those three plus Route in reach. Pad filter is S / M / L, with the current ship's size marked as `Pad {size}, current ship`. Station rows show kind, name, arrival, system, distance as `X ly · N jump(s)`, then allegiance, faction, and state from Spansh.
- **Ships: Info and Engineering.** The old Content tab is Info. Info and Engineering sit together; Coriolis and EDSY sit to the right of that row. Hull art is CMDR Qohen Leth's cartoon vectors (CC BY-NC-SA 4.0). Info lists approximate pitch / roll / yaw as whole numbers. Stored modules have their own Engineering page.
- **Engineer access.** Unlock Status still reads unlocked, invited, known, locked, or barred. The next engineer you can work with now has an orange left edge. Access marks are CMDR Robert Phillips's rank art. Credits live in [NOTICE.md](https://github.com/spadaval/astromech/blob/main/NOTICE.md).
- **Trade.** Commodities (Sell, Buy, My cargo, Route) uses the same lookup chrome as Galaxy: pad filter, station rows, and the rest of the Trade modes from alpha.1.

## What has not been checked in the game

The four in-game sessions in [v1.0.0-alpha.1](https://github.com/spadaval/astromech/blob/main/docs/releases/v1.0.0-alpha.1.md#what-has-not-been-checked-in-the-game) still apply. Add these window walks on Windows, with the app installed from this release.

- **Walk the restyled pages** (part of astromech-snqt). Do: open Trade (Sell, Buy, My cargo, Route), Galaxy (Services, Outfitting, Shipyard, Route), Ships (Info and Engineering on a known hull), Stored modules, and Engineers. Look for: one orange nav row, pad marks that match the current ship, Find going to the right page on Enter, blur leaving the Find box without navigating, Coriolis and EDSY opening the right build, and the next-engineer mark on someone you can work with now.
- **Trade sell and buy in the new chrome** (astromech-1per, astromech-4su3). Do: the same sell and buy lookups as alpha.1, from the restyled Commodities page. Look for: prices and stations still match the quote, allowing for the age of the data.

## Known limits

The [v1.0.0-alpha.1 limits](https://github.com/spadaval/astromech/blob/main/docs/releases/v1.0.0-alpha.1.md#known-limits) still hold.

- **Pitch / roll / yaw.** Info shows approximate hull handling as whole numbers. They are a stand-in from the ship catalogue, not live telemetry.
- **Unsigned.** The installer is not signed, so SmartScreen warns on each setup.exe. In-app updates are signed and checked.
